# Calculadora simple


## ¿Que hace este proyecto?

A través de la pagina https://www.finect.com/fondos-inversion/FR0000989626-Groupama_tresorerie_ic
se realiza un scrapper y se obtiene el valor liquidativo que ofrece la página y se guarda en datos.csv separado por; cada día se programa una tarea para lanzar el get, al cabo de un mes se puede calcular rentabilidad con la siguiente formula:

(VL hoy / VL hace un mes − 1) × 12
