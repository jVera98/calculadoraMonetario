# Calculadora simple


## ¿Que hace este proyecto?

A través de la pagina https://www.finect.com/fondos-inversion/FR0000989626-Groupama_tresorerie_ic
se realiza un scrapper y se obtiene el valor liquidativo del mes anterior y del actual para aplicar la siguiente formula:

(VL hoy / VL hace un mes − 1) × 12
